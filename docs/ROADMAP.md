# Roadmap

## Phase 0 — completed in v0.1.0

- 100-agent catalog and invariants
- Explainable rule-based findings
- Human-authority policy
- Hash-chained SQLite audit store
- Safe simulator, CLI, API and local dashboard
- Tests, CI and container packaging

## Phase 1 — evaluation quality

- Structured benchmark corpus of synthetic incidents
- Per-team precision, recall and calibration reports
- Property-based policy tests
- Signed catalog and policy bundles
- External audit-head anchoring

## Phase 2 — controlled model assistance

- Provider-neutral model interface
- Local/offline model option
- Prompt-injection isolation and output schema enforcement
- Cost, latency and token budgets
- Model cards and repeatable evaluation gates

## Phase 3 — reviewed integrations

- Authenticated operator identities and role-based access
- Read-only telemetry connectors for systems explicitly owned by the operator
- Two-person approval for high-impact actions
- Signed, reversible response plans
- Staging-only integration tests

No phase permits autonomous retaliation, offensive intrusion or removal of meaningful human control.
